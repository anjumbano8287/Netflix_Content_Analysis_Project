# Netflix_Content_Analysis_Project
Netflix Content Analysis Dashboard using Power BI to analyze 8,800+ Netflix movies and TV shows with interactive visualizations, KPI metrics, genre analysis, ratings analysis, yearly trends, and audience insights using Python, SQL, and Excel.

# All the steps mentioned  For this project :
1. Netflix.csv: Data Set need to clean and find out insights from them

   
2. open file Netflix-Cleaning_step1 : run all the code and we get 4 different files and also cleaned files with the help of libraries
   
3. Run commands of Netflix_db_step 2A : download my sql and run all mysql commands that make table or database
   
4. open file EDA-Netflix-step 3 : run the commands and get some insightfull charts that helps in visualization
   
5. Run commands of Netflix_step_2c: So all data cleaned load in the mysql
    
6. Download mysql connecter
    
7. open Power Bi and load the data which is in mysql
    
8. Now all tables is added you can visualize what ever insight you want
